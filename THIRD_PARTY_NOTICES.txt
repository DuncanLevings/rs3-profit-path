Derived from the local static snapshot bundled in DuncanLevings/rs3-monster-lookup:
https://github.com/DuncanLevings/rs3-monster-lookup
Its embedded data was built 2026-10-22. The inherited bundle does not provide
individual article revision IDs; this snapshot is not a claim of current Wiki data.

Profit Path retains monster identity, drop sections, rates, quantities, roll counts,
conditions and notes. It omits monster stats, maps, locations, search indexes and
historical prices, and records rows labelled Not sold as untradeable reference data.
Repeated strings, drop rows and sections are shared in generated Lua tables.

Editable source, exact input hashes and full inherited source notices are recorded
in catalogue-source/monsters.json and catalogue-source/monster-source-notices.txt.
These are maintainer inputs; runtime uses data/monsters.lua and monster_data.lua.
No Monster Data Core runtime dependency or implementation code is bundled.

Calculator reference reviewed 2026-10-28:
https://runescape.wiki/w/Template:Mmgtable/doc?oldid=36863324
https://runescape.wiki/w/Module:Mmgtable?oldid=37167449
The source establishes per-hour/per-kill input distinctions, per-item output tax
rounding and cost-based ROI. Profit Path's calculator is independently written.
It uses GEPL instant-buy input and instant-sell output trade quotes instead of
the Wiki's guide prices. Zero-cost ROI is shown as not applicable, not infinity.
